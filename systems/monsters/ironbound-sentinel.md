# Ironbound Sentinel

## Lore

**Origin:** Dwarven vault-golems and Iron Pact war-engines; still patrol ruins with empty orders.

**Description:** Humanoid plate of riveted iron; furnace-slit visor; slow, inexorable.

**Weaknesses:** Rust agents (acid); command sigil override (Engineering DC 16).
