# Tomb Dust Attribute System

Strength (STR): Physical power; melee damage and carrying capacity.  
Agility (AGI): Speed, reflexes, AC when armor allows, ranged attacks, movement.  
Stamina (STA): Health, endurance, resilience.  
Intellect (INT): Knowledge, reasoning, spell potency, mana pool.  
Spirit (SPI): Willpower, magical resistance, mana regeneration, healing.  
Luck (LUC): **Fortune only**—session luck points, not a modifier on every roll (see [resolution.md](resolution.md)).

## Ability scores and modifiers

Attributes are rolled at creation (see [character/creation.md](../character/creation.md)). Use the **modifier** on d20 tests:

**Modifier = floor((score − 10) / 2)**

| Score | Modifier |
|-------|----------|
| 1 | −5 |
| 2–3 | −4 |
| 4–5 | −3 |
| 6–7 | −2 |
| 8–9 | −1 |
| 10–11 | +0 |
| 12–13 | +1 |
| 14–15 | +2 |
| 16–17 | +3 |
| 18–19 | +4 |
| 20+ | +5 or higher (GM) |

SPI is used for **Wisdom-style** saves and willpower checks. INT is used for **arcane** spell attacks and knowledge.
