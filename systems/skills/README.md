# Skills

All uncertain outcomes use **d20 tests** ([core/resolution.md](../core/resolution.md)).

- **Checks:** [skill-checks.md](skill-checks.md) — formula, DCs, XP
- **Combat math:** [combat/calculations.md](../combat/calculations.md) — **canonical** PB, skill bonus, attacks, damage, Dodge, Magical Defense
- **Progression:** [progression.md](progression.md) — XP and gold costs

## Skill bonus vs skill level

| Use | Source |
|-----|--------|
| **d20 attack rolls, skill checks, saves** | **Skill bonus** from tier table in [combat/calculations.md](../combat/calculations.md) |
| **Techniques, duration, die upgrades, caps** | **Skill level** (1–10) where the skill entry says so |

Category files list per-skill techniques. Unless a skill says otherwise:

- **Check:** d20 + ability mod + PB + skill bonus vs DC  
- **Melee attack:** d20 + STR mod + PB + skill bonus vs AC  
- **Ranged attack:** d20 + AGI mod + PB + skill bonus vs AC  
- **Melee damage:** weapon die + STR mod + skill bonus  
- **Ranged damage:** weapon die + AGI mod + skill bonus (typical)
