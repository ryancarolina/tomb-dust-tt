# NPC services catalog (TD-074)

Hub NPCs offer **services** during **preparation** and **aftermath** ([world/extraction.md](../world/extraction.md)). Use this template on every NPC page.

## Service template

| Field | Meaning |
|-------|---------|
| **Service** | What the NPC provides |
| **Cost** | Gold, favor, or time |
| **DC** | d20 test if any (ability + PB + skill bonus vs DC) |
| **Availability** | When / how often |
| **Faction gate** | Minimum rep or license required |

**Payment:** Registry towns accept stamped contracts; fences pay in coin minus margin (see [equipment/economy.md](../equipment/economy.md)).
