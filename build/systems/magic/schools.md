# Schools of magic

Six schools cover common delver magic. **Spell Focus** (Spellcasting 3+) applies to **one** chosen school (+1 attack and save DC).

| School | id | Theme | Typical sites |
|--------|-----|-------|----------------|
| **Pyromancy** | `pyromancy` | Fire, heat, smoke | Forges, ash wights |
| **Ward** | `ward` | Barriers, dismissal, binding | Tombs, Registry wards |
| **Biomancy** | `biomancy` | Plants, poison, healing sap | Woods, Verdant Vale |
| **Necromancy** | `necromancy` | Dead, fear, cold grave | Undercrypts, Shadowfen |
| **Ether** | `ether` | Thin-veil, force, disruption | EP layers, larvae |
| **Divine** | `divine` | Aven's light, consecration, mend | Chapels, Novice/Priest paths |

## Arcane vs divine

| Tradition | Attack / save mod | Typical casters |
|-----------|-------------------|-----------------|
| **Arcane** | **INT** mod + PB + Spellcasting skill bonus | Apprentice, Hedge Wizard, Mage |
| **Divine** | **SPI** mod + PB + Spellcasting skill bonus | Novice, Acolyte, Priest |

**Divine** school spells always use the divine tradition. All other schools default to **arcane** unless a class feature says otherwise.

**Deity flavor (optional):** Divine spells may invoke [Aven](../deities/aven.md) (light, mend, turn undead) or regional saints; mechanics unchanged. See [deities/README.md](../deities/README.md#divine-casting-td-034).

## Learning spells

| Caster profile | Starting spells | Gain new spells |
|----------------|-----------------|-----------------|
| Tier 1 with Spellcasting | 2 spells, tier ≤ 1, from allowed schools | +1 spell per class tier; tier ≤ class tier |
| Hedge Wizard / Mage path | +1 school at tier 2 promotion | See [classes/progression.md](../classes/progression.md) |

**Allowed schools by base class (creation):**

| Class | Schools |
|-------|---------|
| Apprentice | Any 2 arcane schools |
| Novice | Divine + one other |
| Others | None unless GM grants a spell scroll or deed |
