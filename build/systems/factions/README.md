## Reputation track (TD-055)

Each player **account** tracks standing **−3 to +3** with major factions. New accounts start at **0** unless backstory sets one faction at **+1** (GM).

### Delver's Registry

| Rep | Effect |
|-----|--------|
| −3 | Blacklist; stamps revoked |
| −2 | Double tax; no insurance |
| −1 | Clerks hostile; +1 day stamp processing |
| 0 | Standard fees |
| +1 | −5 gp on next stamp |
| +2 | Survey contract queue; fence introductions |
| +3 | Moot advocate; one free stamp renewal per season |

**AV-GRID:** Edgecombe clerks (`27-D` margin), Breley lower town (`32-C`).

### Iron Pact

| Rep | Effect |
|-----|--------|
| −3 | Seizure on underdeep extract |
| −2 | +50% Pact toll on `UG` layers |
| −1 | Cold escorts in crystal delves |
| 0 | Standard vault treaties |
| +1 | Ignore minor depth overruns once |
| +2 | Shared survey data (`31-C-UG-3`) |
| +3 | Co-stamp on vault wings |

**AV-GRID:** `31-C-UG-3`, `32-C-UG-2`.

### Knights of the Ninety-Ninth Night

| Rep | Effect |
|-----|--------|
| −3 | Arrest near rift cells |
| −2 | No `BV` / stacked EP escort |
| −1 | Mandatory escort fees |
| 0 | Standard patrol |
| +1 | Blessing (+1 save vs shadow, 1/session) |
| +2 | Holt licenses (`32-C`) |
| +3 | Knight adjunct on Black Vale contracts |

**AV-GRID:** `32-C`, `47-B`, `47-B-BV`.

### Verdant Vale (informal)

| Rep | Effect |
|-----|--------|
| ≤ −2 | Sabotaged maps; grotto encounters +1 tier |
| 0 | Ignored |
| ≥ +2 | Safe passage through `WM` grottos; healing spring rumor |

**AV-GRID:** Whispering Marches (`27-D`, `40-C`).

Adjust rep at **aftermath** or when fiction demands; record on account sheet.
