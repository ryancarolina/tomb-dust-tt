# Deities

Aven (sun) and Thar (moon) withdrew after creation; worship is cultural, not always organized clergy.

- [aven.md](aven.md) — creation, order, knights, engineers
- [thar.md](thar.md) — change, night, honest chaos

Myth: [lore/aventhar-creation.md](../lore/aventhar-creation.md). Festivals: [events/](../events/README.md).

## Divine casting (TD-034)

| Topic | Rule |
|-------|------|
| **Attribute** | **SPI mod** on divine spell attacks and save DC (not INT) |
| **Skill** | Spellcasting skill bonus still applies |
| **School** | Spells in the **divine** school use divine tradition ([magic/schools.md](../magic/schools.md)) |
| **Flavor** | **Aven** — mend, consecrate, turn undead, radiant smite. **Thar** cultists use necromancy/ether; not divine despite SPI casters in fiction |
| **Minimum kit** | Five divine spells in [magic/spells.md](../magic/spells.md): Mend Light, Consecrate Ground, Turn Ash, Sun Smite, Sanctuary Hymn |

Novice and Priest paths start with divine school access at creation.
